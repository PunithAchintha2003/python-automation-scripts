# Log Analyzer

A Python-based log analysis tool that reads log files and generates a summary of INFO, WARNING, and ERROR messages.

This project is part of my Python Automation Toolkit, developed as part of my journey toward AI Infrastructure and MLOps engineering.

---

## Features

- Read log files
- Analyze log entries
- Count INFO messages
- Count WARNING messages
- Count ERROR messages
- Calculate total log entries
- Generate a summary report
- Save the report to a text file
- Handle missing log files

---

## Technologies Used

- Python 3
- pathlib
- collections.Counter
