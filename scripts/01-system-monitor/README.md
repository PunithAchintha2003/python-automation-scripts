# System Monitor

A Python-based system monitoring tool that collects and reports CPU, memory, and disk usage.

This project is part of my Python Automation Toolkit, developed as part of my journey toward AI Infrastructure and MLOps engineering.

---

## Features

- Monitor CPU usage
- Monitor memory usage
- Monitor disk usage
- Display system information
- Generate a formatted system report
- Save the report to a text file
- Log system monitoring activities
- Log errors and failures

---

## Technologies Used

- Python 3
- psutil
- datetime
- logging
